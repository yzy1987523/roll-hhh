## 1. TipManager（提示系统）

### 功能
- 显示 1 秒提示信息后自动隐藏
- 全局调用方式

### API
```gdscript
extends Node  # Autoload

# 显示提示（默认1秒后隐藏）
func show_tip(text: String, duration: float = 1.0) -> void
```

### 使用示例
```gdscript
TipManager.show_tip("棋盘格已满，无法移出")
```

### UI 布局
```
┌────────────────────────┐
│    ┌──────────────┐    │
│    │   提示文字    │    │  ← 屏幕顶部居中
│    └──────────────┘    │
└────────────────────────┘
```

## 2. PopupSystem（弹窗系统）

### 功能
- 统一弹窗系统，替代各处散落的详情面板
- 半透明遮罩禁止背景交互
- 按钮可单独显示/隐藏

### API
```gdscript
extends Node  # Autoload

# 显示弹窗
# title: 标题（物品名/角色名）
# content: 内容（详细说明）
# description: 说明（确认键作用，如"是否购买？"）
# confirm_text: 确认键文字（null则隐藏）
# close_text: 关闭键文字（null则隐藏）
# on_confirm: 确认回调
# on_close: 关闭回调
func show(
    title: String,
    content: String = "",
    description: String = "",
    confirm_text: String = null,
    close_text: String = null,
    on_confirm: Callable = null,
    on_close: Callable = null
) -> void

# 隐藏弹窗
func hide() -> void
```

### 使用示例
```gdscript
PopupSystem.show(
    "战士",
    "等级: 5\n血量: 100\n攻击: 30",
    "是否移出角色？",
    "移出",
    "关闭",
    Callable(self, "_on_confirm"),
    Callable(self, "_on_close")
)
```

### UI 布局
```
┌────────────────────────┐
│ ░░░░░░░░░░░░░░░░░░░░░░ │  ← 半透明遮罩
│ ░░░┌──────────────┐░░░░ │
│ ░░░│    标题      │░░░░ │
│ ░░░├──────────────┤░░░░ │
│ ░░░│    内容      │░░░░ │
│ ░░░├──────────────┤░░░░ │
│ ░░░│    说明      │░░░░ │
│ ░░░│ [关闭] [确认] │░░░░ │
│ ░░░└──────────────┘░░░░ │
└────────────────────────┘
```

## 3. 宿舍页面

### 功能
- 4x4 网格显示宿舍角色（最多16个）
- 按等级从高到低排列
- 点击角色弹出详情弹窗
- 标记移出，关闭时执行移出逻辑
- 棋盘满时提示无法移出

### 数据结构
```gdscript

const DORM_CAPACITY := 16
var marked_for_removal: Array = []  # 标记移出的角色索引

func mark_for_removal(dorm_index: int) -> void
func unmark_for_removal(dorm_index: int) -> void
func get_empty_board_count() -> int
func can_remove_marked() -> bool
```
