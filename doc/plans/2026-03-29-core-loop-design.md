## 一、核心循环总览

### 阶段流转

```
┌─────────────┐    结束回合     ┌─────────────┐
│   备战阶段   │ ──────────────→ │   战斗阶段   │
│  (36能量)   │                │  (自动结算)  │
└─────────────┘ ←────────────── └─────────────┘
     ↑                              │
     │     领取奖励后回归            │ 跳过/自动结束
     └──────────────────────────────┘
```

- **备战阶段**：玩家消耗能量生成角色、合成升级、调整站位、宿舍存取、献祭等操作
- **战斗阶段**：点击"跳过"可瞬间结算，或观看动画等待自动结束
- **循环终止条件**：我方全员阵亡 → 结束游戏（保留图鉴）

## 三、数据结构

### 3.1 游戏状态

```gdscript
var game_state: Dictionary = {
    "phase": "prepare",           # "prepare" | "battle" | "shop" | "game_over"
    "gold": 0,
    "energy": 36,
    "max_energy": 36,
    "battle_turn": 0,
    "round": 1
}
```

### 3.2 Buff 效果系统

所有道具、遗物、特技效果基于 Buff 系统实现：

```gdscript
class BuffEffect:
    var id: int                   # Buff序号（索引）
    var type: String               # "damage", "heal", "shield", "energy", etc.
    var value: int                 # 效果数值
    var target: String             # "self", "ally", "enemy", "all"
    var trigger: String            # "on_hit", "on回合结束", "on合成", etc.
```

### 3.3 角色数据

```gdscript
class Character:
    var id: int                   # 角色序号（索引）
    var job: int                  # 0=战士, 1=法师, 2=牧师
    var level: int                # 1-16
    var hp: int
    var max_hp: int
    var attack: int
    var defense: int
    var skill_id: int             # 特技序号（索引）
    var skill_level: int           # 特技等级
    var buffs: Array[BuffEffect]  # 当前buff列表
    var position: Vector2i         # 棋盘坐标，(-1,-1)表示宿舍
```

### 3.4 物品数据

```gdscript
class Item:
    var id: int                   # 物品序号（索引）
    var type: int                 # 0=道具, 1=遗物
    var name: String
    var buffs: Array[BuffEffect]  # 物品提供的buff效果
    var stackable: bool            # 是否可叠加
```

### 3.5 数据存储

```gdscript
var board: Array[Character]        # 棋盘，索引0-35对应位置
var dormitory: Array[Character]    # 宿舍
var items: Array[Item]            # 道具背包
var relics: Array[Item]            # 遗物（常驻生效）
var encyclopedia: Array[bool]     # 图鉴解锁状态，序号对应角色id
```

## 四、战斗流程

```
战斗阶段开始
      │
      ▼
┌─────────────────────────┐
│ 1. 我方全员同步攻击     │ ← 先手优势
│    - 集火敌方单体       │
│    - 伤害 = 我方攻击 - 敌方防御 │
└─────────┬───────────────┘
          │
          ▼
┌─────────────────────────┐
│ 2. 检查敌方是否全阵亡   │
│    是 → 我方胜利        │
│    否 → 继续           │
└─────────┬───────────────┘
          │
          ▼
┌─────────────────────────┐
│ 3. 敌方出手攻击         │
│    - 攻击第一排         │
│    - 若前排无人则顺延    │
│    - 伤害 = 敌方攻击 - 我方防御 │
└─────────┬───────────────┘
          │
          ▼
┌─────────────────────────┐
│ 4. 检查我方是否全阵亡   │
│    是 → 我方失败 → 结束 │
│    否 → battle_turn++  │
└─────────┬───────────────┘
          │
          ▼
┌─────────────────────────┐
│ 5. 检查回合数 ≥ 999    │
│    是 → 平局            │
│    否 → 返回步骤1       │
└─────────────────────────┘
```

**胜负处理**：

- 胜利 → 弹出奖励 → 回归备战（角色满血）
- 失败 → 结束游戏（保留图鉴）
- 平局 → 回归备战（无奖励）

## 五、备战阶段操作

```
进入备战阶段
      │
      ▼
┌─────────────────────────────────────┐
│ 可选操作：                          │
│                                     │
│ [生成角色]                          │
│   └─ 消耗1能量 → 随机1-3级角色 → 放棋盘空位 │
│                                     │
│ [拖拽角色]                          │
│   └─ 棋盘↔棋盘 换位                 │
│   └─ 棋盘 ↔ 宿舍 存取               │
│                                     │
│ [合成角色]                          │
│   └─ 两个同职业+同等级角色 → 高1级  │
│   └─ 触发特技强化（3级/6级/10级/16级）│
│                                     │
│ [献祭角色]                          │
│   └─ 返还能量 = 2^(level-1)         │
│                                     │
│ [使用道具/遗物]                     │
│                                     │
│ [商店] → 进入商店界面               │
│                                     │
│ [结束回合] → 进入战斗阶段           │
└─────────────────────────────────────┘
```

### 6.1 商店规则

- 仅备战阶段可进入商店

- 商店内可消耗金币购买物品

## 十一、敌人系统

### 11.1 敌人节奏（每9轮一个完整循环）

```
普通1 → 普通2 → 精英1 → 普通3 → 普通4 → 精英2 → 普通5 → 普通6 → BOSS
   1       2       3        4       5       6        7        8       9
```

- 精英出现：第3轮、第6轮
- BOSS出现：第9轮

### 11.2 敌人属性

| 类型 | 特点                             |
| ---- | -------------------------------- |
| 普通 | 血量低、攻击低、防御低、无特技   |
| 精英 | 血量中、攻击中、防御中、有特技   |
| BOSS | 血量高、攻击高、防御高、强力特技 |

随循环数增加，同类型敌人数值递增。

## 十三、存档系统

### 13.1 存档方式

| 登录状态 | 存档位置            | 存档内容        |
| -------- | ------------------- | --------------- |
| 未登录   | LocalStorage        | 本地存档        |
| 已登录   | LocalStorage + 云端 | 本地 + 云端同步 |

### 13.2 存档内容

- 棋盘角色
- 宿舍角色
- 当前能量
- 遗物、道具
- 图鉴解锁信息
- 金币数量
- 当前循环数

### 13.3 自动存档

- 每次操作后**自动保存**
- 刷新网页/重新进入可读取进度

### 13.4 战败后保留数据

- ✓ 图鉴解锁信息
- ✓ 云端排行榜记录
- ✗ 棋盘角色、宿舍、能量、遗物、道具、金币、循环数 → 全部清空

## 十七、转职系统

### 17.1 转职触发

| 来源 | 规则 |
|------|------|
| 默认 | 生成角色时固定概率生成转职角色 |
| 遗物 | 转职令牌：生成时概率+5% |

### 17.2 转职职业分支

| 原始职业 | 转职方向 |
|----------|----------|
| 战士 | 狂战士、骑士、大剑士 |
| 法师 | 魔导师、死灵法师 |
| 牧师 | 大祭司、圣骑士 |

### 17.3 转职规则

- 转职后变成**新职业分支**
- 新职业有**独立属性成长**和**专属特技**
- 转职后保留**原等级**，属性**重新计算**

### 17.4 获取方式

| 来源 | 规则 |
|------|------|
| 商店 | 购买转职道具（有库存限制） |
| 生成 | 默认5%概率生成转职角色 |
