## 第二阶段：备战阶段核心玩法

| 任务 | 内容 | 依赖 | 状态 |
|------|------|------|------|
| 2.1 | **备战阶段 UI 重构** — 按设计稿布局：顶部资源栏、遗物栏、道具栏/宿舍/商店按钮、6×6 棋盘、底部生成按钮+结束回合 | 1.1 | ✅ |

| 2.5 | **献祭系统** — 返还能量 = `2^(level-1)` | 1.1, 1.4 | 🔲 |

## 第三阶段：战斗系统

| 任务 | 内容 | 依赖 | 状态 |
|------|------|------|------|
| 3.1 | **敌人数据生成** — 9 轮循环节奏（普通×6 + 精英×2 + BOSS×1），数值随循环递增 | 1.2 | 🔲 |
| 3.2 | **战斗引擎** — 我方先手同步攻击 → 检查敌方 → 敌方攻击前排 → 检查我方，回合循环至分出胜负或 999 回合平局 | 1.2, 3.1 | 🔲 |
| 3.3 | **战斗阶段 UI** — 敌方头像/血条、棋盘展示、播放/加速/跳过按钮 | 2.1 | 🔲 |
| 3.4 | **Buff 系统核心** — BuffEffect 的 trigger 触发机制（on_hit / on_attack / on_round_start 等），支撑角色特技和敌人特技 | 1.2 | 🔲 |
| 3.5 | **胜负结算** — 胜利→奖励弹窗→回归备战（满血）；失败→游戏结束（保留图鉴）；平局→回归备战（无奖励） | 3.2 | 🔲 |
