# 美术资源清单 / Art Asset List

## 项目概况 / Project Overview

- **项目类型**: 6x6战棋游戏 (6x6 Tactical Game)
- **渲染方式**: Godot 4.6.1, 2D/UI, 无需3D渲染
- **美术风格**: 建议扁平化/卡通风格 (Flat/Cartoon Style)
- **主色调**: 深蓝底色 (#1A2A4A / #2A3A5A), 角色职业颜色鲜明

## 八、推荐文件格式 / Recommended File Formats

| 类型 | 格式 | 优点 |
|-----|------|------|
| 角色/敌人 | PNG (32-bit带透明) | 支持半透明, 无锯齿 |
| UI按钮 | PNG (32-bit带透明) | 支持圆角和阴影 |
| 图标 | PNG 或 SVG | SVG可无损缩放 |
| 背景 | PNG 或 WebP | WebP压缩率高 |
| 特效 | PNG序列 或 Spritesheet | 动画流畅 |

---

## 九、命名规范 / Naming Convention

```
[类型]_[名称]_[状态].png

示例:
char_warrior_idle.png      # 角色_战士_待机
char_mage_attack.png        # 角色_法师_攻击
btn_spawn_warrior_hover.png # 按钮_生成战士_悬停
enemy_boss_idle.png         # 敌人_BOSS_待机
```
