网页合成对战游戏初步需求文档

一、技术开发基础要求

采用 Godot 4.6.1 引擎搭建，选用 GL Compatibility 渲染器，保证网页端兼容适配；游戏导出为 HTML5 格式，保存路径指定为 /workspace/output/，在 8080 端口配置 COOP/COEP 响应头部署运行，全程针对浏览器性能优化，保证加载流畅、动画无卡顿、运行无闪退，适配主流网页浏览器。

二、核心玩法与游戏循环

游戏为肉鸽类合成对战玩法，核心循环分为备战阶段和战斗阶段，两轮阶段交替进行，直至我方全员阵亡则本局游戏结束，全程保留图鉴解锁信息，支持本地存档与云端排行榜记录。

（一）阶段一：备战阶段（核心界面与规则）

1. 界面固定展示元素
2. 能量条：实时显示当前剩余能量、本局能量上限，清晰直观
3. 6*6棋盘格：角色摆放主战场，支持角色拖拽、换位、合成操作
4. 结束回合按钮：备战完毕后点击，直接切换至战斗阶段
5. 生成点按钮：共3个，分别对应战士、法师、牧师三类角色，样式通过颜色、图标区分，点击单次消耗1能量
6. 角色详情页：点击棋盘或宿舍内任意角色弹出，展示角色完整属性、等级、职业、特技，页面内置献祭按键和图鉴入口
7. 宿舍按钮：角色背包入口，存放闲置角色，不占用棋盘站位
8. 设置按钮：包含音效开关、游戏重置、存档查看等功能
9. 遗物栏：常驻界面，直接展示已获得遗物的图标、样式，悬停可查看遗物效果
10. 道具栏：存放各类临时道具、角色礼包，点击可直接使用
11. 阶段核心规则

本阶段仅可进行角色生成、合成、站位调整、宿舍存取、角色献祭、图鉴查看、遗物道具查看操作，不可触发战斗；每回合初始能量固定36点，能量不可跨回合留存，当回合剩余能量清零，能量耗尽仍可手动点击结束回合，进入战斗阶段。

（二）阶段二：战斗阶段（核心界面与规则）

1. 界面固定展示元素
2. 敌人面板：展示敌方头像、血条、攻击值、防御值、特性技能，信息清晰醒目
3. 战斗回合数：实时统计当前战斗回合数，上限999回合
4. 6*6棋盘格：保留备战阶段的角色站位，所有角色实时显示血条，搭配攻击、受击、阵亡帧动画
5. 播放/暂停键：控制战斗动画的播放与暂停，随时可控
6. 加速键：支持多档位战斗加速，可随时切换
7. 跳过键：直接跳过战斗动画，瞬间结算战斗结果
8. 遗物栏：同备战阶段，常驻展示已获得遗物图标，效果全程生效
9. 阶段核心规则

敌我双方轮流出手攻击，我方全员同步进攻，敌方单次攻击一排，战斗全程搭配帧动画和技能特效；直至一方全员阵亡，或达到999最大回合数，战斗阶段终止，结算胜负后回归备战阶段或结束游戏。

三、角色系统（属性简化+合成+特技规范）

（一）基础属性设定（极简数值化）

角色固定分为战士、牧师、法师三大职业，初始生成等级为1-3级，等级上限16级，属性仅保留血量、防御、攻击、特技四项，无额外浮动数值，成长规则统一固定，无随机偏差。

1. 各职业1级基础属性

- 1级战士：3血、1防、1攻；特技：每3回合格挡一次敌方伤害，格挡后本次受击无伤
- 1级牧师：2血、0防、0攻；特技：每回合为身旁最近的己方伤员回复1点血量
- 1级法师：1血、0防、2攻；特技：每回合攻击，额外造成1点穿透伤害，无视敌方防御

2. 等级成长规则

每合成提升1级，角色血量、攻击、防御三项核心属性各加1点；合成至3级时，对应职业特技直接强化一次；后续每提升3级，特技效果小幅递增，16级为顶级，无法继续合成。

（二）角色合成规则

必须使用2个同职业、同等级的角色，方可合成1个高1级的同职业角色；合成无任何资源消耗，无失败概率，100%合成成功，合成后原两个角色自动消失，新角色继承原有站位；合成至3级触发特技强化，16级封顶，禁止继续合成。

（三）角色图鉴系统

通过角色详情页的图鉴入口，进入对应角色的专属升级链图鉴页，查看该职业从1级至16级的完整属性、特技成长路径、升级条件；图鉴解锁信息永久保留，即使本局战败、临时数据清空，已解锁的角色图鉴依旧正常显示，未解锁图鉴做灰度遮挡处理。

（四）宿舍（背包）系统

宿舍为角色备用背包，备战阶段可将棋盘角色拖拽存入宿舍，也可将宿舍内角色拖拽至棋盘参战；存放的角色不参与战斗、不占用棋盘空间，本局内存放无额外消耗，战败后宿舍内所有角色一并清空。

（五）献祭系统（指数递增收益）

献祭即角色回收，点击详情页献祭按键即可执行，系统弹出二次确认弹窗，严防误操作，献祭后角色永久移除，返还对应能量，能量收益严格遵循指数递增规则：

- 低等级角色按等级对应指数梯度返还能量，等级越高，返还能量呈指数级大幅上涨
- 公式为：能量=2^(level-1)，比如16级角色，返还

   点能量
- 默认支持单个角色献祭，预留批量献祭功能拓展口

四、战斗机制细则

（一）基础战斗规则

1. 攻击顺序：我方先手全员攻击，随后敌方出手，双方交替进攻，轮流出手
2. 敌方攻击：单次攻击一整排，优先攻击第一排，若前排无存活角色，伤害自动顺延至下一排，直至命中己方存活角色
3. 我方攻击：全场存活角色同步出手，统一集火敌方单体目标，伤害结算规则：我方攻击 - 敌方防御 = 实际扣血，结果低于0则扣0点血量
4. 阵亡判定：角色血量降至0立即阵亡，触发阵亡帧动画，随即移出棋盘，不再参与后续战斗
5. 胜负判定：敌方全员阵亡，我方胜利，返回备战阶段领取奖励；我方全员阵亡，本局战败，直接结束游戏；达到999回合上限，强制判定平局，无任何奖励，返回备战阶段

（二）战斗表现形式

战斗全程采用帧动画展示，角色Idle、攻击、受击、阵亡均配有帧动画；技能触发、格挡、回血、穿透伤害等效果，搭配对应的视觉特效，提升战斗观感；支持暂停、调速、跳过，跳过战斗不影响结算结果和奖励获取。

（三）战斗控制功能

- 暂停/播放：随时启停战斗动画，方便查看战场局势
- 加速：支持1倍、2倍、5倍、10倍四档加速，战斗中可自由切换
- 跳过：直接跳过所有战斗动画，瞬间结算出结果，无消耗、无冷却

五、遗物与道具系统（预留拓展机制）

遗物为全局永久加成道具，获得后立即生效，常驻遗物栏展示对应图标，预留完整连携、构筑、效果叠加机制，支持后续拓展职业羁绊、套装效果、组合buff等玩法；遗物核心效果包含但不限于：生成点概率刷出转职角色、每回合能量上限提升、生成角色概率直升高级、指定职业属性加成、献祭能量返还提升、战斗属性增幅等。

道具栏存放角色礼包、临时增幅道具等，使用后立即生效，助力阵容构筑，同样预留充足拓展空间，可后续新增各类功能性道具。

六、敌人系统（预留拓展机制）

敌人拥有固定的血量、攻击、防御、特性技能，随循环回合推进，敌人数值、特性逐步变强；预留敌人连携、特性组合、特殊战场机制，可后续拓展敌方羁绊、场景buff、特殊攻击模式，提升游戏策略深度和长线可玩性。

七、战败与存档机制（肉鸽模式）

1. 本局战败后，立即结束当前对局，清空棋盘角色、宿舍角色、当前能量、遗物、道具等所有本局临时数据，回归游戏初始状态
2. 永久保留角色图鉴解锁信息，已解锁的图鉴不会随战败清空，下次开局依旧可见
3. 支持本地自动存档，未登录状态下，本地存档保留本局进度、图鉴信息；刷新网页、重新进入游戏，可直接读取本地进度继续游玩
4. 登录后，额外同步云端数据，自动记录玩家最高循环数，计入排行榜

八、新手教学系统

首次进入游戏，自动触发新手教学，采用遮罩+分步提示的形式，教学期间仅提示区域可交互，其余位置屏蔽点击，彻底防止误操作，教学步骤贴合核心玩法，循序渐进：

1. 第一步：指引点击生成按钮，消耗能量生成角色
2. 第二步：指引拖拽同职业同等级角色，完成合成操作
3. 第三步：指引调整角色站位，排布攻防阵型
4. 第四步：指引查看角色详情、使用献祭功能、打开图鉴
5. 第五步：指引点击结束回合，进入战斗阶段，熟悉基础战斗操作
6. 教学完成后自动关闭，后续开局不再触发

九、排行榜系统

1. 未登录状态：可正常本地游玩，完整体验全部玩法，不展示、不统计排行榜相关数据
2. 登录状态：完成权限校验后，系统自动记录玩家本局最高循环数，上传并保存至飞书文档，实时读取数据生成排行榜，展示玩家排名、对应最高循环数，默认显示随机数字ID，可以自行添加昵称。
3. 排行榜仅统计最高通关循环数，数据定期同步，保证准确公平

十、机制预留与后续拓展

- 预留角色连携、职业羁绊、遗物构筑体系，支持后续开发阵容组合玩法
- 预留敌人特性、敌方组合、特殊战场机制，便于后期提升策略性
- 预留转职角色、高阶特技、稀有遗物的拓展接口，方便后续版本更新

十一、性能与交互优化

1. 优化网页加载速度、角色渲染效率、动画帧率，杜绝卡顿、闪退问题
2. 所有操作配备点击反馈和文字提示，能量不足、棋盘已满等异常操作，及时弹窗提示
3. 界面布局简洁规整，操作逻辑通顺，贴合网页端常规操作习惯
4. 存档数据做轻量化处理，不占用过多浏览器缓存，保证运行流畅
